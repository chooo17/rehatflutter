# QRIS Statis

Letakkan gambar QRIS merchant **Rehat** di sini sebagai **`qris.png`**.

- QRIS statis ini bisa didapat dari bank/e-wallet merchant (mis. dari dashboard
  GoBiz, OVO Merchant, dll.) **tanpa** integrasi payment gateway.
- Pelanggan memindai QR ini dari aplikasi pembayaran apa pun (GoPay/OVO/DANA/m-banking)
  lalu membayar sejumlah total pesanan.
- Setelah uang masuk, **admin** menandai pesanan **"Dibayar"** dari menu
  *Kelola Status* di detail pesanan.

Selama `qris.png` belum ada, aplikasi menampilkan placeholder.
