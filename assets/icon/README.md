# App Icon

Letakkan logo **Rehat** di sini sebagai `app_icon.png` (disarankan 1024×1024, PNG).

Setelah file ada, generate ikon launcher Android & iOS:

```
& "C:\Users\thezu\flutter\bin\flutter.bat" pub run flutter_launcher_icons
# atau
dart run flutter_launcher_icons
```

Konfigurasi ada di `pubspec.yaml` pada bagian `flutter_launcher_icons`.
